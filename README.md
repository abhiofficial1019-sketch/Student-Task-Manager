# Student Task Manager (React)

A beginner-friendly task manager built with React, Vite, and Local Storage.

## Features
- Add tasks with a category and optional due date.
- Mark tasks complete or pending.
- Filter all, pending, and completed tasks.
- Delete tasks.
- Dashboard counts and completion percentage.
- Tasks persist in the browser with Local Storage.
- Responsive layout.

## Run it
1. Install Node.js (LTS) if it is not already installed.
2. Extract this folder and open it in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local address shown in the terminal.

## Main files
- `src/App.jsx`: React logic and UI.
- `src/style.css`: styling.
- `src/main.jsx`: React entry point.

This is a frontend-only learning project. Data is stored in the current browser, not a server or database.
